# 🌐 Tufail.dev – Personal Portfolio

A modern and responsive personal portfolio website showcasing my skills, projects, achievements, and experience as a Frontend Developer and Electronics & Communication Engineering student.

## 🚀 Features

- Responsive design for all devices
- Modern dark UI with smooth animations
- About, Skills, Projects, Experience & Achievements sections
- Contact form with EmailJS integration
- Downloadable resume
- Project filtering
- Interactive animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- EmailJS

## 📁 Project Structure

```
.

```

## 💻 Run Locally

1. Clone the repository

```bash
git clone https://github.com/Tufail2004/Tufail.dev.git
```

2. Open the project folder

3. Open `index.html` in your browser
